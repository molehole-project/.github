# Molehole 🕳️

하나의 구멍에서 시작되는 땅속 네트워크

## ✨ Project Overview

Molehole은 개인 기록과 콘텐츠를 중심으로 한 블로그 서비스입니다.

## 🧱 Repositories

| Repository | Description |
|----------|------------|
| **molehole-backend** | Spring Boot 기반 백엔드 서버 |
| **molehole-frontend** | React 기반 프론트엔드 |
| **molehole-docs** | API 명세, ERD, 설계 문서 (선택) |

---

## 🔧 Tech Stack

### Backend
- Java 17
- Spring Boot 3.x
- Spring Security (JWT + Refresh Token)
- JPA / QueryDSL
- MySQL

### Frontend
- React
- TypeScript

### Infra
- EC2
- AWS S3
- Nginx
